## 六、已知限制（如实说明）

1. 本机未安装 Android SDK，无法执行 `./gradlew assembleDebug` / `lint`，
   也无法在模拟器上运行 TalkBack；因此**没有真机实测结果**，第四节提供的是待复验用例。
2. 静态审计不能覆盖 TalkBack 的实际朗读效果、焦点移动的动态表现、
   弹窗与列表滚动时的播报时机、系统字体放大后的布局裁切；这些需按第四节人工复验。
3. `android:accessibilityHeading` 自 API 28 起生效，`minSdk 24` 的低版本设备会安全忽略该属性，
   但 `sp` 字体缩放与 48dp 触摸目标在低版本同样有效。
4. 项目中的 DeepSeek / 高德 API Key 由 `local.properties` 注入（未纳入仓库），
   编译运行前需自行配置，不影响无障碍适配内容。
