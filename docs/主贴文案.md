一、适配项目
《软件工程》课程项目「校园智慧二手平台」（Android 原生 Java，校园二手商品交易系统）。
按任务书「（2）Android 移动项目」分支，依据 Android 官方无障碍规范做视障友好适配。
本次仅做无障碍适配，未新增任何业务功能。

二、适配说明（修改点）
1. 语义信息：新增 res/values/a11y_strings.xml 集中管理 60+ 条中文无障碍文案；
   为 54 处控件补/改 contentDescription，全部引用 @string 资源。
   把「返 / ← / ? / ⚙ / × / 刷」等符号按钮改为「返回上一页 / 帮助与交易说明 /
   设置 / 移除第 N 张商品图片 / 刷新商品流」等明确语义；商品图片、头像、图标不再被
   朗读为无意义的「图片」。把 23 处纯装饰元素标记为 importantForAccessibility="no"。
   列表图片在 Adapter 中动态朗读「<商品名> 的商品图片」，购物车复选框、
   未读角标也补充了所属对象与单位。

2. 键盘与焦点：从 Java 中提取 90 个实际绑定点击监听的控件，补 focusable="true"
   （共 98 处），纠正搜索框原本写死的 focusable="false"；为 28 个输入框建立显式
   nextFocusForward 键盘导航链；6 个列表条目根布局可键盘聚焦。
   用 AccessibilityDelegate 把「TextView/容器模拟按钮」声明为 Button 角色，
   底部导航、分类格子、信息流 Tab 支持朗读「已选中 / 未选中」。

3. 屏幕切换、弹窗、列表：切换 Fragment 后播报「已切换到发现页 / 购物车 …」；
   把 93 处 Toast 提示统一改为 A11y.toast（保留原 Toast，同时发送无障碍播报事件），
   使登录失败、发布成功、加入购物车、下单/发货/收货、校验错误等结果可被 TalkBack 感知；
   弹窗保留原有标题/按钮文本并纳入表单焦点链；空状态声明为 polite 实时区域。

4. 低视力可读性：11 处触摸目标由 32/36/40/44dp 提升到 48dp；
   文字尺寸全部为 sp；把 text_tertiary、danger 两个颜色加深以满足 WCAG 2.1 AA
   对比度要求；状态同时用文字与选中态表达，不单靠颜色。

5. 功能完整性：未新增/删除任何 Activity、Fragment、数据模型或业务分支；
   逐文件 diff 为「修改 48 个已有文件、新增 11 个文件（无障碍资源/工具类/脚本/文档）、
   删除 0 个文件」，见仓库 docs/变更清单.md。

三、测试工具与记录
工具：自研可复现静态审计 tools/a11y_audit.py、综合校验 tools/verify_a11y.py、
javalang（Java AST 语法解析）；真机侧计划使用 TalkBack、Accessibility Scanner、
外接键盘/方向键、系统字体放大。

已在本机真实执行：
- 无障碍静态审计（同一版脚本对比）：改造前 151 项问题（110 个 error）
  → 改造后 0 项，退出码 0。其中图片无标签 30→0、硬编码文案 2→0、
  触摸目标不足 11→0、表单缺焦点顺序 28→0、Java 绑定点击但不可聚焦 76→0。
- 综合静态校验：121 个 XML 全部可解析；Java 资源引用、A11y 方法名与 import、
  括号结构均无误；54 个 Java 文件全部通过 javalang 语法解析；问题数 0。
- 适配规模：contentDescription 54 处、装饰元素屏蔽 23 处、focusable 98 处、
  nextFocusForward 28 处、标题 17 处、实时区域 14 处、Toast 播报 93 处。
- 功能回归（静态）：业务代码未改，A11y.toast 内部仍显示原 Toast，行为一致。

说明：本机未安装 Android SDK / 模拟器，未执行 Gradle 编译与真机 TalkBack 实测；
仓库 docs/测试记录.md 已提供 17 条真机复验用例（步骤、预期效果、对应修改点），
结果列如实留空待复验，未按实测填写。

四、成果仓库（GitHub）
https://github.com/YWHUTER/Android-APP-Accessibility

仓库内含：完整可编译工程、docs/适配说明.md、docs/测试记录.md、
docs/变更清单.md、docs/a11y-audit-baseline.md（改造前）、
docs/a11y-audit-report.md（改造后）、docs/verification-report.md，
以及 tools/ 下 4 个可复现的审计 / 校验 / 改造脚本。
验证命令：
  python tools/a11y_audit.py --strict
  python tools/verify_a11y.py --strict
