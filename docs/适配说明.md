# 适配说明 · 揭榜任务二（视障友好适配）

> 任务书要求：**不新增任何业务功能**，仅在本人已完成的课程项目基础上，
> 针对现有界面与交互逻辑做视障用户友好的无障碍适配改造。
> 本文逐条说明修改点、依据与作用，全部改动可在仓库中按文件核对。

| 项 | 内容 |
| --- | --- |
| 课程项目 | 校园智慧二手平台（校园二手商品交易系统） |

## 二、规范依据

1. **Android Developers — Make apps more accessible**：为所有非文本内容提供
   `contentDescription`；纯装饰性图片设 `importantForAccessibility="no"`；
   可交互控件必须可聚焦、有可朗读标签；状态变化应可感知。
2. **Android Developers — AccessibilityNodeInfo / 自定义视图无障碍**：
   用 `AccessibilityDelegate` 为「TextView / 容器模拟按钮」声明 `Button` 角色，
   用 `setSelected` 表达选中态，用 `TYPE_ANNOUNCEMENT` 播报操作结果。
3. **Material Accessibility / WCAG 2.1 AA**：触摸目标不小于 48dp；
   文字尺寸使用 `sp` 以跟随系统字体缩放；正文与背景对比度 ≥ 4.5:1；
   状态不能仅依靠颜色区分。
4. **Android 键盘 / 方向键导航**：`focusable`、`nextFocusForward` / `nextFocusDown`
   显式控制焦点顺序，保证无触摸操作路径完整可用。

## 三、逐条对应任务书要求

### （1）为界面控件设置合理的语义信息，确保 TalkBack 可正确朗读

**问题**：原项目中大量按钮实际是 `TextView` / `LinearLayout`，文字为
「返」「←」「?」「⚙」「×」「刷」「✕」等符号；商品图片、头像、图标没有
`contentDescription`，TalkBack 只会朗读「图片」「按钮」或无意义符号。

**改动**：

- 新增 `res/values/a11y_strings.xml`，集中定义 60+ 条中文无障碍文案，
  所有 `contentDescription` 均引用 `@string/`，不硬编码文本。
- 为 **54 处**控件补 / 改 `contentDescription`，典型示例：

| 控件 | 原朗读 | 现朗读 |
| --- | --- | --- |
| `btn_chat_back` / `btn_back`（text="返"） | 「返」 | 「返回上一页」 |
| `btn_community_back`（text="←"） | 符号 | 「返回上一页」 |
| `btn_detail_help`（text="?"） | 符号 | 「帮助与交易说明」 |
| `btn_profile_settings`（text="⚙"） | 符号 | 「设置」 |
| `btn_remove_preview_1/2/3`（text="×"） | 符号 | 「移除第 N 张商品图片」 |
| `btn_scan`（text="刷"） | 「刷」 | 「刷新商品流」 |
| `iv_search_camera` | 「图片」 | 「拍照发布闲置」 |
| `fab_new_message` | 「图片」 | 「发起新私信」 |
| `nav_post`（原硬编码 "发布闲置"） | 硬编码 | 改为 `@string/cd_nav_post` |
| `layout_search_box` / `card_purchases` / `card_sales` | 无可朗读内容 | 「搜索商品，激活后可输入关键词」等 |

- 把 **23 处**纯装饰元素标记为 `importantForAccessibility="no"`，
  避免 TalkBack 朗读毛玻璃背景、导航图标、搜索图标、文字头像、
  未读数字角标等无意义内容。涉及 `activity_main.xml`、`fragment_discovery.xml`、
  `fragment_message.xml`、`fragment_post.xml`、`fragment_profile.xml`、
  `item_conversation.xml` 及多个页面的无 id 装饰图标。
- **列表项图片改为动态语义**：Adapter 在 `onBindViewHolder` 中调用
  `A11y.itemImage(...)`，把「商品图片」替换为「<商品名> 的商品图片」；
  涉及 `DiscoveryItemAdapter`、`CartListAdapter`、`MyListingAdapter`、
  `OrderListAdapter`、`ConversationAdapter`。
- **购物车复选框**补充所属商品名（`cd_cart_item_checkbox`），
  不再只朗读「未勾选」；**会话未读角标**朗读「N 条未读消息」而非数字「3」。
- 页面标题（17 处）声明 `android:accessibilityHeading="true"`，
  TalkBack 可使用「按标题导航」。

### （2）保证界面可通过键盘、方向键、无障碍导航完整操作，焦点逻辑清晰

**问题**：项目大量用「TextView / 容器 + `setOnClickListener`」模拟按钮，
XML 里没有 `focusable`；键盘 / 方向键无法聚焦，静态 XML 也看不出这些控件可点击。
另有一处 `layout_search_box` 原本显式写死 `android:focusable="false"`。

**改动**：

- 从 Java 源码中提取 **90 个**实际绑定了点击监听的 `R.id.xxx`，
  在布局中逐一补 `android:focusable="true"`（共 **98 处** `focusable="true"`），
  使键盘 / 方向键 / 开关控制可到达所有交互控件。
- 纠正 `fragment_discovery.xml` 中 `layout_search_box` 的 `focusable="false"` → `true`。
- 为 **28 个** `EditText` 建立显式 `android:nextFocusForward` 链，
  按屏幕视觉顺序连接下一个可聚焦控件（登录、注册、发布、编辑资料、
  重置 / 修改密码、搜索、聊天、地点选择等表单），键盘 Tab 顺序可预期。
- 为 6 个 `item_*.xml` 列表条目根布局声明 `focusable="true"`，
  使 RecyclerView 条目可用键盘逐条聚焦并激活。
- Java 侧用 `A11y.asButton(...)` 把容器 / TextView 在无障碍节点上声明为
  `Button` 角色（`info.setClassName(Button.class.getName())`），
  TalkBack 会朗读为「xxx，按钮」并提示可激活；涉及底部导航 5 项、
  搜索框、10 个分类格子、3 个信息流 Tab。
- 用 `A11y.asTab(...)` / `View.setSelected(...)` 表达选中状态，
  TalkBack 朗读「已选中 / 未选中」：底部导航、信息流 Tab、分类格子、发布项。
- `tools/a11y_audit.py` 新增 **A11Y-010** 规则，静态关联 Java 与 XML，
  专门检查「Java 绑定了点击但布局未声明可聚焦」的情况（改造前命中 76 项）。

### （3）保证屏幕切换、弹窗、列表等常用界面在 TalkBack 下可正常使用

- **屏幕切换**：`MainActivity.showTab()` 在切换 Fragment 后调用
  `A11y.announce(...)` 播报「已切换到发现页 / 消息页 / 发布页 / 购物车 / 我的页面」；
  底部导航项同步更新 `selected` 状态。
- **操作结果播报**：把 **93 处** `Toast.makeText(...).show()` 统一替换为
  `A11y.toast(...)`——保留原有 Toast 视觉提示，同时通过
  `AccessibilityManager` 发送 `TYPE_ANNOUNCEMENT` 事件，
  使登录失败、注册成功、发布成功、加入购物车、下单 / 发货 / 收货、
  校验错误、AI 生成结果等信息对视障用户可感知。
  涉及 14 个 Activity / Fragment，业务分支逻辑未改动。
- **弹窗**：项目所有 `AlertDialog` 均已有 `setTitle` / `setMessage` /
  正负面按钮文本，TalkBack 可朗读；对话框内的 `EditText` 均带 `hint`，
  并已纳入焦点链（`dialog_change_password.xml`、`dialog_reset_password.xml`、
  `dialog_new_post.xml`）。弹窗操作后的成功 / 失败提示同样走 `A11y.toast` 播报。
- **列表**：列表条目根可聚焦、图片有动态商品名、文字头像 / 装饰图已排除、
  复选框与未读角标有语义、空状态 TextView 声明 `accessibilityLiveRegion="polite"`
  （14 处），筛选无结果等动态内容变化会自动播报。
- **状态不只靠颜色**：订单状态、推荐 / 搜索模式、筛选 Tab 同时保留中文文字标签，
  并补充 `selected` 状态；不会仅凭颜色变化传达信息。

### （4）确保原有功能在无障碍模式下可用、完整、不中断

- 未新增 / 删除任何 Activity、Fragment、数据模型、网络请求、数据库操作或业务分支。
- 所有业务方法的调用链保持不变；唯一涉及原有调用的改动是把 `Toast` 换成
  `A11y.toast`（内部仍调用 `Toast.makeText(...).show()`，视觉行为完全一致）。
- `docs/变更清单.md` 逐文件对比原仓库：**修改 48 个已有文件、新增 16 个文件、
  删除 0 个业务文件**；新增文件全部是无障碍资源、工具类、校验脚本与文档。
  另按 `.gitignore` 排除 15 个原仓库误提交的本地 IDE / 构建缓存文件
  （`.idea/`、`.vscode/`、`.gradle-user/`），与源码及功能无关，清单中已逐项列出。
- 触摸目标由 32 / 36 / 40 / 44dp 提升到 48dp（11 处），
  文字尺寸全部为 `sp`（原项目已符合），颜色对比度加深
  （`text_tertiary` `#737688` → `#5B5F72`，`danger` `#D93F5C` → `#C22646`），
  提升低视力用户在浅色卡片上的可读性，不影响功能。

## 四、核心实现：`app/src/main/java/com/example/homework/util/A11y.java`

纯适配工具类，**不含任何业务逻辑**，公开 10 个方法：

| 方法 | 作用 |
| --- | --- |
| `announce(Context/View, CharSequence)` | 通过无障碍服务发送 `TYPE_ANNOUNCEMENT` 播报 |
| `toast(Context, CharSequence)` | 显示 Toast + 同步播报（替身，行为与原 Toast 一致） |
| `label(View, CharSequence)` | 设置语义标签并同步 `importantForAccessibility` |
| `decorative(View...)` | 装饰性元素移出无障碍树 |
| `heading(View)` | 声明标题，支持 TalkBack 按标题导航 |
| `liveRegion(View)` | 声明 polite 实时区域 |
| `asButton(View, CharSequence)` | 声明 Button 角色 + 可聚焦 + 可朗读标签 |
| `asTab(View, CharSequence, boolean)` | 在 `asButton` 基础上补充选中状态 |
| `itemImage(View, CharSequence)` | 列表图片动态语义 / 无图时标记装饰 |
| `rootView(Context)` | 从 Activity 获取播报用根 View |

兼容性：使用 AndroidX `ViewCompat` / `AccessibilityDelegateCompat`，
`minSdk 24` 下可正常运行；`accessibilityHeading` 等属性在低版本被安全忽略。
